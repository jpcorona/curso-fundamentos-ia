# Trabajo final · Construye tu agente

Desarrolla un agente a tu elección y explícalo en un video de máximo 3 minutos.


> **SDK verificado (agosto de 2026).** Estos materiales usan `azure-ai-projects` **2.4.0**, API v1, agentes versionados, Conversations y Responses. No mezcles ejemplos 1.x/classic. Revisa la [referencia 2.4.0](https://learn.microsoft.com/python/api/overview/azure/ai-projects-readme), el [quickstart 2.x](https://learn.microsoft.com/azure/foundry/quickstarts/get-started-code) y [File Search](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/file-search).

## Entregables

1. Repositorio GitHub reproducible.
2. Agente funcional con al menos una herramienta, RAG o Code Interpreter.
3. Matriz de pruebas.
4. Video de máximo 3 minutos.
5. Ficha de arquitectura, límites y riesgos.

## Tipos de agente

| Tipo | Ejemplo | Clave |
|---|---|---|
| Herramientas/APIs | clima, agenda, inventario | validar y confirmar |
| RAG documental | políticas, manuales, FAQ | evidencia y ausencia |
| Analista | CSV, presupuesto | cálculo reproducible |
| Asistente de flujo | onboarding, tutor | estado y salida |
| Router | RRHH + clima | selección observable |
| Generador con revisión | correos, resúmenes | humano aprueba |

## Fórmula de propuesta

“Para **[usuario]**, mi agente ayuda a **[tarea]** usando **[fuente/herramienta]**, entrega **[resultado]** y evita **[riesgo]**”.

## Requisitos mínimos

- Instrucciones específicas.
- Una capacidad real.
- Variables de entorno.
- Manejo de un error.
- Tres pruebas documentadas.
- README reproducible.

## Video de 3 minutos

| Tiempo | Contenido |
|---|---|
| 0:00–0:20 | problema y usuario |
| 0:20–0:45 | solución y límite |
| 0:45–1:10 | arquitectura |
| 1:10–2:10 | demo real |
| 2:10–2:35 | caso límite |
| 2:35–2:55 | aprendizaje y mejora |
| 2:55–3:00 | cierre |

## Rúbrica

| Criterio | Puntos |
|---|---:|
| Problema y usuario | 10 |
| Funcionamiento | 25 |
| Herramientas/RAG | 20 |
| Calidad y seguridad | 15 |
| Pruebas | 10 |
| Documentación | 10 |
| Video | 10 |
| **Total** | **100** |

## Integridad y seguridad

Puedes usar IA, pero debes comprender el código. Atribuye fuentes. No uses datos confidenciales. Acciones sensibles requieren vista previa y confirmación humana.
